# 과제: 선착순 좌석 예약 서비스

## 배경

우리 팀은 소규모 공연과 팝업 행사의 좌석을 판매합니다. 지금까지는 행사마다 스프레드시트와 메신저로 신청을 받았는데, 인기 행사에서는 신청이 몇 초 사이에 몰리면서 정원보다 많은 사람에게 "확정" 안내가 나가는 일이 반복됐습니다. 사과 연락과 환불 처리에 운영팀이 며칠씩 매달렸습니다.

다음 행사부터는 신청을 API로 받으려고 합니다. 처음 버전은 아래 기능이면 충분합니다.

## 필요한 것

- 운영자가 정원을 정해 행사를 등록할 수 있어야 합니다.
- 사용자가 행사 좌석을 예약할 수 있어야 하고, 예약이 확정되었는지 바로 알 수 있어야 합니다.
- 사용자가 나중에 자기 예약의 상태를 다시 확인할 수 있어야 합니다.
- 누구나 행사의 남은 자리를 확인할 수 있어야 합니다.
- 한 사용자는 같은 행사에 한 자리만 가질 수 있습니다.

지난번 같은 일은 다시 없어야 합니다. **남은 자리가 하나일 때 많은 사람이 동시에 예약해도, 확정되는 사람은 한 명이어야 합니다.**

여기 적히지 않은 부분은 실제로 이 서비스를 운영한다고 생각하고 판단해 주세요. 왜 그렇게 정했는지도 남겨 주세요.

## 실행 환경

| 항목 | 내용 |
| --- | --- |
| 실행 | 저장소 루트의 `compose.yaml`로 실행합니다. 서비스 이름은 `app`이고, DB 서비스는 넣지 않습니다. |
| 포트 | `app`은 8080 포트에서 HTTP 요청을 받습니다. |
| 상태 확인 | `GET /health`는 서비스가 요청을 처리할 준비가 되면 200을 돌려줍니다. |
| DB | PostgreSQL을 쓸 수 있습니다. 접속 정보는 환경 변수 `DATABASE_URL`(`postgresql://<user>:<password>@<host>:<port>/<database>`)로 주어지며, 처음에는 비어 있습니다. |
